# Càlcul de seccions

Aplicació didàctica per al mòdul **0962 Sistemes de potència** (RA1, apartat 1.9) per treballar el càlcul de seccions de conductors en línies monofàsiques i trifàsiques.

- **Teoria**: criteri de caiguda de tensió i d'intensitat màxima admissible, deducció de les fórmules, conductivitats i errors típics.
- **Laboratori**: controls lliscants per veure com afecten la longitud, la potència i la secció a la caiguda de tensió i a l'escalfament.
- **Calculadora**: resolució pas a pas de qualsevol línia (amb potència o intensitat, Cu/Al, PVC/XLPE).
- **Exercicis**: generador d'exercicis en tres nivells, amb correcció, pistes sobre errors habituals i solució pas a pas. Inclou una fitxa imprimible amb 6 exercicis i les solucions.
- **Taules**: intensitats admissibles orientatives (mètode B1, 30 °C) i conductivitats.

És una sola pàgina HTML (`index.html`), sense instal·lació. Obre-la al navegador o publica-la amb GitHub Pages. Les fórmules es mostren amb KaTeX (cal connexió a internet).

> Les intensitats admissibles són orientatives. Consulteu sempre la taula oficial (ITC-BT-19 / UNE-HD 60364-5-52) per a cada sistema d'instal·lació.
